# КОНТУР · Kontur

**Прокси-клиент для Google Chrome на Windows.** Добавьте свою подписку, проверьте задержку, выберите сервер и подключитесь прямо из окна расширения.

КОНТУР работает в текущем профиле Chrome через локальный помощник и ядро Xray. Он не меняет системный прокси Windows и не направляет трафик других приложений через выбранный сервер.

## Что умеет КОНТУР

- Импортирует подписки по ссылке и поддерживает серверы VLESS, VMess, Trojan и Shadowsocks.
- Показывает подписки отдельными группами: их можно сворачивать, обновлять и переименовывать.
- Проверяет задержку одного сервера, целой подписки или всех серверов сразу.
- Сохраняет избранное и позволяет отдельно настроить сортировку и фильтры для каждой подписки.

КОНТУР не выдаёт собственные серверы: для подключения нужна ваша подписка или ссылка на сервер. «Пинг» в интерфейсе — время HTTPS-запроса через проверяемый сервер.
